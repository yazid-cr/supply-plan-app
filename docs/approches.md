# Trois cas, trois approches différentes (TP1)

- **Pharmacie : alerter sur un dosage dangereux** → Règles métier, validées
  par le pharmacien. (b) chaque alerte se justifie ; (d) une erreur peut être grave.
- **Règlement intérieur : répondre aux salariés** → RAG : des réponses citées.
  (a) pas d'étiquettes, des documents ; (b) on relit la source.
- **Supply chain : repérer les demandes à risque** → Apprentissage automatique.
  (a) des données étiquetées existent ; (c) coût par demande faible.
